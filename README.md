# TS3-TS6 Notifier

Красивый оверлей для **TeamSpeak 3** и **TeamSpeak 6**: кто сейчас на канале, кто говорит, статусы участников — с гибкой настройкой внешнего вида.

![Node](https://img.shields.io/badge/Node.js-20%2B-339933) ![License](https://img.shields.io/badge/license-MIT-blue)

## Мини-гид: как запустить

1. **Скачайте приложение** — `TS3-TS6-Notifier-Setup-*.exe` из раздела [Releases](../../releases) — и запустите (от себя достаточно; запуск от администратора — по желанию).
2. **Выберите источник данных** — окно настроек откроется само при первом запуске (⚙ → **Связь**):
   - **TeamSpeak 3** — включите плагин **ClientQuery** в самом клиенте: **Сервис → Настройки → Плагины → ClientQuery**. Плагин входит в состав [клиента TeamSpeak 3](https://www.teamspeak.com/en/downloads/) — отдельно ставить нечего. **Если плагина нет в списке аддонов** — установите его отсюда: [ClientQuery на myTeamSpeak](https://www.myteamspeak.com/addons/L2FkZG9ucy85NDNkZDgxNi03ZWYyLTQ4ZDctODJiOC1kNjBjM2I5YjEwYjM%3D). Ключ API находится в *Settings…* этого плагина — оверлей подхватит его сам. Официальная тема с описанием: [TeamSpeak Client 3.1.3 / ClientQuery](https://forum.teamspeak.com/threads/130474).
   - **TeamSpeak 6 (и TS5)** — включите **Remote Apps** (Настройки → Remote Apps) и один раз разрешите подключение.
   - **Демо-режим** — просто посмотреть, как всё выглядит.
3. **Настройте вид** (по желанию): ⚙ → **Вид** — тема, прозрачность, положение на экране; перетащить панель можно кнопкой «Переместить оверлей» («✓» — сохранить, «✗» — отменить).
4. **Для OBS**: ⚙ → **Ещё** → **«Скопировать ссылку для OBS»** → в OBS добавьте **Browser Source** и вставьте ссылку. Всё — TS будет показываться поверх игры. (Проверить картинку можно и без OBS: откройте скопированную ссылку в браузере.)
5. **Обновления** приложение скачивает само. Когда обновление готово — нажмите **«Перезапустить сейчас»** (кнопка в «Ещё» или в уведомлении), либо просто закройте приложение — обновление установится при выходе.

## Возможности

- **Состав канала в реальном времени** — список участников текущего канала с аватарами-инициалами и значками статусов (микрофон выключен, звук выключен, «Отошёл», Channel Commander, Priority Speaker).
- **Индикация речи** — говорящие подсвечиваются: свечение аватара, акцентная подложка и анимированный индикатор (столбики / кольцо / точки).
- **Три источника данных**:
  | Клиент | Источник | Что нужно |
  |---|---|---|
  | TeamSpeak 3 | ClientQuery (TCP `127.0.0.1:25639`) | включённый плагин ClientQuery + API key |
  | TeamSpeak 5/6 | Remote Apps (WebSocket `ws://127.0.0.1:5899`) | включённые Remote Apps + одноразовое разрешение приложения |
  | — | Демо-режим | ничего — оверлей оживает без клиента |
- **8 тем оформления** (Стекло, Полночь, Иней, Неон, Изумруд, Кармин, Янтарь, Моно) — у каждой свой акцент и характер; акцентный цвет, прозрачность панели, размытие фона, свечение, скругление, масштаб, шрифт, положение на экране (4 угла + **раздельные отступы по горизонтали и вертикали 0–240 px**).
- **Настройки элементов**: аватары, значки, заголовок, счётчик участников, «говорящие — сверху», режим «только говорящие», компактный режим, анимации, скрытие query-ботов и пустой панели.
- **Иконки групп вместо аватаров** — иконка серверной группы (класса) показывается прямо в списке; TS3 читает их из кеша клиента (PNG/WebP/TGA поддержаны).
- **Channel Commander** — золотая корона, как в TeamSpeak.
- **Шёпот** — говорящие шёпотом выводятся отдельной секцией с плавным затуханием.
- **Сообщения чата** — всплывают на оверлее и исчезают через настраиваемую задержку (личные можно скрыть).
- **Звуковая панель** — отдельное окно из трея в стиле RP-Soundboard: сетка кнопок со звуками, горячие клавиши, пресеты, выбор устройства вывода (звук слышно «от вашего имени» в TeamSpeak).
- **Авто-подключение TS3** — API key подхватывается автоматически из ClientQuery (можно ввести и вручную).
- **Мульти-монитор** — выбор экрана, на котором показывать оверлей. Оверлей всегда поверх: окно настроек открывается отдельно и не прячет его.
- **Русский и английский** интерфейс (автоопределение системы).
- **Профили настроек** — экспорт/импорт JSON, URL-параметры для OBS-сцен.
- Прозрачный фон — готово для **OBS Browser Source**.

## Быстрый старт

### Вариант 1. Готовое приложение (Windows) — рекомендуется

Скачайте **TS3-TS6-Notifier-Setup-*.exe** из раздела [Releases](../../releases) и запустите.

Приложение работает в **трее**:
- оверлей поверх всех окон (поверх игры в оконном/безрамочном режиме);
- **клик-сквозь** — мышь проходит сквозь оверлей прямо в игру;
- правый клик по иконке → **Data source** (Демо / TS3 / TS6), настройки, «Запуск с Windows», показ/скрытие оверлея, выход.

> Windows может показать SmartScreen при первом запуске — «Подробнее» → «Всё равно запустить» (exe не подписан сертификатом).

### Вариант 2. Веб-режим (из исходников)

```bash
npm install
npm start          # сервер + оверлей на http://localhost:3000
```

Откройте <http://localhost:3000> — сразу работает **демо-режим** с живыми «участниками». Кнопка ⚙ открывает настройки.

### Сборка exe самостоятельно

```bash
npm install        # требует Node.js 20+
npm run dist       # → dist/TS3-TS6-Notifier-Setup-1.0.0.exe
```

Либо доверьтесь CI: каждый тег `v*` собирает exe автоматически в GitHub Actions (`.github/workflows/release.yml`) и прикладывает к релизу.

## Подключение к TeamSpeak 3

1. В клиенте TS3: **Сервис → Настройки → Плагины → ClientQuery** — включите плагин и откройте его *Settings…*. Плагин встроен в [клиент TeamSpeak 3](https://www.teamspeak.com/en/downloads/) и обычно ставится/обновляется автоматически через myTeamSpeak. **Нет в списке аддонов?** Установите вручную: [ClientQuery на myTeamSpeak](https://www.myteamspeak.com/addons/L2FkZG9ucy85NDNkZDgxNi03ZWYyLTQ4ZDctODJiOC1kNjBjM2I5YjEwYjM%3D) ([официальная тема](https://forum.teamspeak.com/threads/130474)).
2. API key **подхватывается автоматически** из ClientQuery (файл `clientquery.ini`). Если хотите вручную — скопируйте ключ из настроек плагина и вставьте в оверлей.
3. В оверлее: **⚙ → Связь → Источник данных → TeamSpeak 3**, при необходимости вставьте ключ, *Переподключить*.

Если подключение не идёт: откройте `%APPDATA%\ts3-ts6-notifier\app.log` — там виден полный обмен с ClientQuery (что отправлено и что ответил плагин).

## Подключение к TeamSpeak 6 (и TS5)

1. В клиенте TS6: **Настройки → Remote Apps** — включите и запомните порт (по умолчанию `5899`).
2. В оверлее: **⚙ → Связь → Источник данных → TeamSpeak 6**, *Переподключить*.
3. При первом подключении клиент покажет запрос на разрешение — подтвердите его (колокольчик уведомлений или **Настройки → Remote Apps**). Ключ API сохранится автоматически.

> Протокол Remote Apps официально не документирован и может меняться между версиями клиента. Если события перестанут приходить — нажмите «Переподключить».

## Настройки оверлея

Вкладка **⚙ → Вид**: тема, акцентный цвет, свечение, прозрачность панели (15–100 %), размытие фона, скругление, масштаб, размер шрифта, угол экрана, **отступы по горизонтали и вертикали (0–240 px)**, язык.

Вкладка **⚙ → Элементы**: какие блоки и значки показывать, индикатор речи, сортировка и компактность, секция «Шёпот», сообщения чата и задержка их исчезновения.

Вкладка **⚙ → Звук**: звуковая панель — загрузите свои звуки (до 8 МБ), назначьте горячие клавиши, выберите устройство вывода и громкость, кнопка «Открыть панель». Есть гид «как звучать в канале» с авто-поиском Стерео микшера (работа без виртуального кабеля).

**Иконки групп** вместо аватаров включаются автоматически: если у групп пользователя есть иконки, они показываются в списке (вкладка «Классы» больше не нужна).

Окно настроек (десктоп) показывает **только настройки**, а оверлей остаётся поверх экрана. На вкладке **Вид** можно выбрать **монитор** для оверлея.

Все изменения применяются мгновенно и сохраняются (localStorage + конфиг сервера).

### Шёпот и чат

- Говорящие **шёпотом** показываются отдельной секцией сверху с плавным затуханием (определение шёпота — лучшая попытка: TS3 отдаёт `targetmode`, TS6 — статус речи ≥ 2).
- **Сообщения чата** появляются внизу панели: канал, личные (ЛС) и серверные. Исчезают через задержку (2–60 с), личные можно отключить.

### Звуковая панель (звук «от вашего имени»)

Windows не даёт программе писать прямо в микрофон — нужен «петлевой» вход. В приложении на вкладке **⚙ → Звук** есть встроенный гид и авто-поиск такого входа. Два способа:

**Способ 1 — Стерео микшер (без установки).** Если звуковая карта его поддерживает (часто Realtek):
1. ПКМ по значку 🔊 → «Звуки» → «Запись» → включите **«Стерео микшер»** (ПКМ → «Показать отключённые устройства»).
2. В TeamSpeak выберите его как микрофон.
3. В оверлее вывод звука оставьте на «Устройство по умолчанию» — звук панели пойдёт в канал.
4. Хотите говорить голосом одновременно: в свойствах реального микрофона включите **«Слушать это устройство»** (вывод — динамики) — Стерео микшер захватит и голос, и звуки.

**Способ 2 — Виртуальный кабель (надёжно).** VB-Cable или VoiceMeeter: вывод панели — на кабель, микрофон в TeamSpeak — кабель. Голос не смешивается с системными звуками, качество выше.

Нажмите кнопку на панели или горячую клавишу — звук придёт в канал «от вас». Горячие клавиши (например, `Ctrl+Alt+1`) работают глобально в десктоп-приложении. Пресеты (монета, тревога, клаксон и т.д.) добавляются одной кнопкой.

### URL-параметры (удобно для OBS)

```
http://localhost:3000/?corner=br&opacity=0.5&accent=22d3ee&clean=1
```

| Параметр | Пример | Что делает |
|---|---|---|
| `corner` | `tl` `tr` `bl` `br` | угол экрана |
| `opacity` | `0.5` | прозрачность панели |
| `accent` | `22d3ee` | акцентный цвет (hex) |
| `theme` | `glass` `midnight` `frost` `neon` | тема |
| `glow` `blur` `radius` `scale` `font` | числа | соответствующие настройки |
| `marginx` `marginy` | числа (0–240) | отступы от краёв экрана (`margin` — оба сразу) |
| `eq` | `bars` `ring` `dots` `none` | индикатор речи |
| `lang` | `ru` `en` | язык |
| `compact` | `1` | компактный режим |
| `clean` | `1` | «чистый» режим: без кнопки настроек и баннера |

### Использование в OBS

1. Запустите `npm start`.
2. В OBS: **Источники → Browser** → URL `http://localhost:3000/?clean=1&corner=tr`.
3. Ширина/высота — размер вашего экрана, фон прозрачный по умолчанию.

Оверлей также можно открыть в обычном окне браузера поверх игры (оконный/безрамочный режим игры).

```
app/
  main.ts               # десктопное приложение (Electron): оверлей, трей, настройки

  icons/                # готовые иконки (png/ico)

  app.ts                # ядро: HTTP + WebSocket сервер, REST API
  index.ts              # CLI-запуск веб-режима

    wire.ts             # парсеры протоколов (TS3 escape/unescape, JSON-помощники)
    ts3.ts              # источник TS3 (ClientQuery, telnet)
    ts6.ts              # источник TS5/6 (Remote Apps, WebSocket)

public/
  index.html            # оверлей + панель настроек
  css/overlay.css       # темы и стили

tools/make-icons.mjs    # рендер иконок из SVG
test/
  protocols.mjs         # тестовый стенд протоколов (21 проверка)
  electron-stub.cjs     # заглушка Electron для smoke-теста
.github/workflows/      # CI: сборка Windows exe + релиз
```

Скрипты: `npm start` (веб), `npm run app` (десктоп в dev), `npm run dist` (exe), `npm test`, `npm run smoke:app`, `npm run typecheck`.

## Ограничения

- **Эксклюзивный полноэкранный режим** игр не поддерживается (для этого нужен нативный оверлей) — используйте оконный/безрамочный режим.
- Аватары генерируются из ника/хэша (TS3/TS6 не отдают картинки аватаров через локальные API). Клиентские хэши аватаров (`client_flag_avatar` / `flagAvatar`) используются для стабильного цвета.
- TS6: если открыто несколько серверных вкладок, оверлей следует за активной (той, где включён микрофон).
- Данные не покидают ваш компьютер: сервер слушает только локальные API клиентов и сам ничего не отправляет наружу.
